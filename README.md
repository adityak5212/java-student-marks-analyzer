# Java Student Marks Analyzer

A beginner-friendly Java project using arrays and loops.

## Features
- Calculate total marks
- Find highest marks
- Find lowest marks
- Calculate average marks
- Find second largest and smallest numbers
- Detect duplicate numbers

## Technologies
- Java
- Arrays
- Loops
- Conditional Statements
